# Arduino experiments

Experiments on the Arduino Uno that are not part of a university TP. Create one folder per experiment from [`../templates/EXPERIMENT_README.md`](../templates/EXPERIMENT_README.md).

Suggested folders, in this order:

1. `01-basics/` digital I/O, `millis()` timing, Serial debugging
2. `02-analog-pwm/` analog input, PWM output
3. `03-sensors/` one folder per sensor
4. `04-actuators/` servo, relay, DC motor with driver, stepper
